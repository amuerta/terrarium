# Fish Screensaver

Fish simulation using linear path with sine function and length-based constraint from spine.

> [!NOTE]
> this project can change the name and features at any time, so to find its previous iterations, check the branches!

## Building

1. Bootstrap build system
```console
    cc -o build build.c
```
2. Build project depending on your platform
```
    ./build linux run # run `./build` to get the list of avilable flags
```
